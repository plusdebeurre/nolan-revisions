# Guide de révision — Thai Grade 2 (rattrapage)

Guide parent pour aider Nolan à rattraper le niveau exigé par le curriculum thaï Grade 2. L’interface des jeux est en **anglais** ; les caractères thaïs apparaissent dans les exercices.

## Ouvrir les jeux

Hub → **Thai** → [`subjects/thai/index.html`](../../subjects/thai/index.html)

## Partie 1 — Alphabet et classes (Trai Yang)

- **44** consonnes au total.
- Première : **ก** (Gor Kai). Dernière : **ฮ** (Hor Nok-huk — hibou).
- Obsolètes (plus utilisées) : **ฃ** (Khuat) et **ฅ** (Khon).
- **3** classes : moyennes (กลาง), hautes (สูง), basses (ต่ำ).
- Comptes : **9** moyennes, **11** hautes, **24** basses.
- Exemple moyenne : **ก**. Exemple haute : **ข**.

Jeux : Mega Quiz Q1–10, **Consonant Class Sort**, **Alphabet Train**, **Obsolete Letter Trap**.

## Partie 2 — Voyelles

- **32** sons de voyelles au total : **18** courtes + **14** longues.
- Courte typique : **-ะ**. Longue typique : **-า**.

Jeux : Mega Quiz Q11–15, **Vowel Length Lab**.

## Partie 3 — Tons

Marques :

| Marque | Nom |
|--------|-----|
| ่ | Mai Ek |
| ้ | Mai Tho |
| ๊ | Mai Tri |
| ๋ | Mai Chattawa |

**5** sons de ton (commun/samun + les 4 marques).

Jeux : Mega Quiz Q16–20, **Tone Mark Match**, **Tone Karaoke**.

## Partie 4 — Consonnes finales (แม่ / Mae)

| Famille | Son final | Exemple |
|---------|-----------|---------|
| แม่ ก กา | aucune finale | หมา |
| แม่กง | NG (ง) | ช้าง |
| แม่กน | N (น) | บ้าน |
| แม่กม | M (ม) | ส้ม |
| แม่เกย | Y (ย) | ยาย |
| แม่เกอว | W (ว) | แมว |
| แม่กก | K (ก) | นก |
| แม่กด | T/D (ด) | เป็ด |
| แม่กบ | P/B (บ) | กบ |

Jeux : Mega Quiz Q21–29, **Mae Ending Safari**, **Mae Memory**.

## Partie 5 — Chiffres thaïs

๑=1, ๒=2, ๓=3, ๔=4, ๕=5, ๖=6, ๗=7, ๘=8, ๙=9.

**๑๑ (11)** se lit **Sip-et** (le 1 final se dit « et », pas « nueng »).

Jeux : Mega Quiz Q30–39, **Thai Digits Race**, **Digit Bingo**.

## Partie 6 — Vocabulaire « Nam Sai »

Dans l’histoire, les éléphanteaux **Bai Bok** et **Bai Bua** mangent de la **glace pilée au sirop** : **น้ำแข็งกด** (nam khaeng kot).

Jeux : Mega Quiz Q40, **Nam Sai Story Quiz**, **Nam Sai Comic Choice**.

## Conseils de révision

1. Faire d’abord les petits jeux ciblés, puis le Mega Quiz (40).
2. Montrer les lettres/tons sur papier en même temps que l’écran.
3. Pour Sip-et : pratiquer 11, 21, 31 à voix haute.
4. Les maths du hub ont aussi de **grandes banques fixes** pour des sessions longues.
